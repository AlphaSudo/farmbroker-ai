## Acceptance and final go/no-go

1. A stranger can use the judge guide to reach the core scenario without code knowledge. If hosted execution fails, complete local setup instructions genuinely work.
2. The video clearly shows request -> accepted quote -> real sandbox payment -> paid procurement -> inspection failure -> AI recovery -> fulfillment/settlement, with a separately identified refund proof.
3. Claims, displayed statuses, provider references, and evaluated numbers agree across video, UI, README, and submission text.
4. Repository/license, demo access, and final public video links work outside the creator's signed-in session.
5. Submission confirmation exists and availability ownership is assigned. Record any outstanding limitation rather than declaring it complete.

## Scope cut

If time is short, simplify screenshots and production polish. Keep the real working proof, readable under-three-minute video, reproducible access, required source/license, and correct submission. No new features or sponsor integrations enter this milestone.
